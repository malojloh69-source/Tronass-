# Tronaccs Трекер

Полная инструкция на русском находится в [README.md](README.md).

Коротко: установите `pip install -r requirements.txt`, задайте BOT_TOKEN,
запустите `python main.py`, отправьте боту `/start`.
Настройки мониторинга доступны через `/settings` или кнопку «Настроить фильтры».
Доступ к трекеру выдаёт администратор в панели бота. Каждый `/start` отправляет новое сообщение.
После уведомления об аккаунте бот прикладывает названия и фото NFT и обычных
подарков с доступным или ожидаемым улучшением, если площадка передала список.
